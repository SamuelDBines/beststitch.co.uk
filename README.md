# beststitch.co.uk

Built static site for Best Stitch, served by GitHub Pages at https://beststitch.co.uk.

Do not edit these files by hand. The source lives in the private bishop-co-tech-free monorepo (`apps/best-stitch`). To update, run `./scripts/pages/deploy-best-stitch.sh` there: it rebuilds the site, copies `dist/` here (keeping `CNAME` and `.nojekyll`) and pushes.
